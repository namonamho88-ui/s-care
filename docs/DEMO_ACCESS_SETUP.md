# 로그인 없는 시연 접속 설정

기본은 비활성화다. 운영 배포 및 공개 시연 활성화는 별도 승인 후 수행한다. 현재 계정 로그인 백엔드를 시연 백엔드로 바꾸지 않는다.

## 배포 구조

- 기존 Vercel 앱의 `BACKEND_URL` → 기존 Railway 백엔드 → 기존 Supabase `brain` 스키마.
- 별도 Railway 서비스(동일 소스)의 `DEMO_BACKEND_URL` → 전용 DB 역할/`brain_demo_showcase` 스키마.
- 계정 쿠키가 우선이다. 계정 세션 없이 허용된 시연 접속일 때만 별도 HttpOnly 시연 쿠키를 발급한다. 관리자 토큰은 시연 쿠키에 사용하지 않는다.
- 브라우저는 API 키/게이트웨이·제어 키/시연 원문 토큰을 JSON으로 받지 않는다. 서버 DB에는 토큰 해시만 저장한다.

## 데이터 준비

DB 관리자가 새 `brain_demo_showcase` 역할 및 같은 이름의 스키마를 생성하고 해당 스키마의 소유/사용/생성 권한만 부여한다. 비밀번호는 비밀 관리 환경에서 설정한다. 기존 `brain` 스키마나 기존 계정 테이블 권한을 부여하지 않는다. Supabase 세션 풀러를 사용할 때 새 역할에 해당하는 로그인 이름과 SSL 연결을 확인한다. 기존 postgres 관리자 계정 재사용 금지.

Flyway는 지정된 시연 스키마에 기존 마이그레이션과 V11을 적용하여 별도 가상 시드만 생성한다. 기존 스키마에 대한 초기화·삭제 작업은 없다. 운영 백엔드에도 V11은 필요하지만 기존 레코드를 삭제하지 않는다.

Neo4j 시연 서버에는 `GRAPH_NAMESPACE=Demo_showcase`를 설정한다. 기존 Asset 라벨과 별도의 노드·제약·의존 관계로 구성한다. `HERMES_PUBLISH_MODE=disabled`를 고정하여 기존 Hermes Skill 파일을 시연 사용자가 변경할 수 없게 한다. REAL 검색은 도구가 비활성화된 기존 공식 Hermes API에 승인된 시연 DB 후보만 전달한다. DEMO는 모델 호출이 없다.

## 접속 허용과 종료

1. `deploy/demo-backend.env.example`, `deploy/demo-vercel.env.example`를 참고하여 새 서비스와 BFF를 설정한다. 서로 다른 32자 이상의 게이트웨이 키·제어 키를 서버에만 저장한다.
2. 시연 종료 시각은 `DEMO_ACCESS_EXPIRES_AT=2026-10-20T09:00:00Z` 같은 ISO UTC 형식으로 지정한다. 화면에서는 KST로 표시한다.
3. `DEMO_ALLOWED_ORIGIN`은 실제 Vercel 도메인과 정확히 일치해야 한다. `DEMO_ALLOWED_IPS`는 발표 장소의 공인 IP를 열거한다. 값이 없거나 접속 IP가 다르면 로그인 없는 접근은 차단된다. Vercel 앞의 별도 프록시를 사용하는 구성은 이 방식의 지원 범위 밖이다.
4. 서버/BFF의 `DEMO_ACCESS_ENABLED=true`가 모두 필요하다. 환경변수 허용 후에는 관리자 계정으로 로그인하여 계정 관리 → 로그인 없는 시연 접속에서 비활성화/재활성화한다.
5. 시연 참가자는 관리자 계정 관리·외부 Skill 게시·시연 설정 변경을 수행할 수 없다. 일반 업무 승인/보고서/평가는 격리된 가상 데이터에서 가능하다.
6. 비활성화 시 서버의 토큰 검사는 즉시 실패하고 SSE도 종료된다. 화면은 다음 요청 또는 최대 5초의 가벼운 세션 확인에서 로그인으로 전환한다. 숨긴 탭은 돌아온 뒤 확인한다. 이미 승인·접수된 백엔드 가상 작업과 저장 데이터는 삭제하지 않는다.

로컬 개발에서는 두 백엔드 포트와 각각 다른 DB 스키마를 사용한다. BFF는 `127.0.0.1`에만 바인딩하고 `DEMO_LOCAL_ONLY=true`, `DEMO_ALLOWED_ORIGIN=http://127.0.0.1:3100`을 설정한다. 이 로컬 옵션으로 공개 호스팅하지 않는다. Vercel 외 호스팅은 기본 차단된다.

IP/Origin 변경, 기간 연장, 시연 서버 재배포는 운영 설정 변경으로 취급한다. 화면의 DEMO/REAL 선택은 접속 허용을 변경하지 않는다.

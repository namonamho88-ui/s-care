# 개발 완료 범위

이 프로젝트는 가상 금융 IT 장애 대응 **시연용 풀스택 애플리케이션**이다. 핵심 시연과 전체 금융 운영환경 도입의 완료 기준은 다르며, 전체 개발이 100% 완료됐다고 표시하지 않는다.

| 영역 | 구현·검증 범위 | 남은 범위 |
|---|---|---|
| 관제·장애 이력 | 실제 API/DB, 고정 시드, 단계 이벤트, 등록·검토·승인·가상 복구·종료, PDF/Excel | 운영 조직의 실제 업무 규칙 적용 |
| Jev | Local jevos 실제 호출, Mock 및 명시적 fallback, 신뢰도·근거 표시, TypeSafe Adapter 계약 테스트 | API 키 확보 후 TypeSafe 실제 호출 검증 |
| Ontology | PostgreSQL 자산/의존 관계, Neo4j 영향 탐색, React Flow 전체화면·영향 필터 | 실제 기업 자산 수집·동기화(현재는 가상 데이터) |
| A2A | 6개 Agent, 공식 0.3.0 JSON-RPC 동기 Task 프로필, 작업 증적 | 전체 A2A 적합성 인증 및 다른 제품 Agent와 상호운용 검증 |
| Hermes | 공식 Nous Agent + OpenAI 실제 검색/초안 생성, 관리자 승인 후 Skill 게시, Mock 구분 | 초안 편집·재생성 UI, 생성 내용 의미 검증 강화 |
| Harness | 근거·권한·실행 제한, 재시도·수동 승인·감사, 50개 정답 시나리오 평가 | 대규모 반복 평가·경계 시나리오 확장 |
| 사용자 인증 | 개인 계정, 1회용 초대, ADMIN/USER, 담당자별 편집 제한, 세션 폐기·감사 구현·배포 및 클라우드 권한 차단 검증 완료 | 기업 SSO/MFA, 이메일 초대 전달, 별도 보안 검토 |
| 배포 | Vercel + Supabase + Railway 통합 시연 및 재시작 보존 검증 이력 | 최종 유료 환경 자원 확정, HA/작업 큐/지속 부하 검증 |

개인 계정/권한 검증과 배포는 완료했다. 다음 우선순위는 관리자·일반 사용자 실제 시연 리허설 → Skill 초안 편집·재생성 → 최종 시연 환경 점검이다. 변경별 실제 통과 결과는 `VALIDATION.md`와 `evidence/`에 별도로 기록한다. 현재 자료만으로 기업 운영환경의 보안·가용성을 인증하지 않는다.

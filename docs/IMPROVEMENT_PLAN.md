# 평가와 운영 흐름 개선

1. 기존 SCN 50건과 Flyway V2는 시연 회귀용으로 보존한다. 신규 한국어 평가셋은 별도 테이블·버전으로 관리한다. 정상 문자 제외, 실제 SmsParser 경로, 근거 부족·복합 원인·부정문을 평가하고 기존 영어 규칙 기준선과 비교한다. 가상 데이터 점수는 실운영 검증 성적으로 표현하지 않는다.
2. 화면은 SSE 이벤트를 묶어서 갱신하며 정상 연결 중 상세 폴링을 제거한다. 숨겨진 탭은 연결/폴링을 중지한다. 목록은 저빈도 동기화와 사용자 갱신으로 다른 사용자 변경을 확인한다.
3. 장애 상태 변경과 작업 등록을 하나의 DB 트랜잭션에 저장한다. SKIP LOCKED로 작업을 가져오고 임대 만료 시 이어받는다. 완료 단계 체크포인트와 멱등 가상 조치를 사용한다. 중단·삭제 및 승인 조건을 재확인한다. 외부 호출은 중복될 수 있으므로 정확히 한 번 실행을 보장한다고 표현하지 않는다.
4. Skill 초안 편집과 재생성은 버전 충돌을 검사하고 이전/이후 내용·사유·행위자·모델 출처를 보존한다. 승인본은 수정하지 않는다.
5. 유사 장애는 종료 이력의 텍스트·유형·자산으로 순위를 계산하고 당시 조치와 유사 근거를 표시한다. 유사도는 원인 확률이 아니다.
6. 단계 체류시간, 첫 사람 대응(MTTA), 복구(MTTR) 및 표본 수를 표시한다. 승인 요청과 SLA 초과 알림을 DB에 저장하고 기본 가상 채널에서 확인한다. 실제 Slack/Teams 발송은 이번 작업에서 활성화하지 않는다.

검증: H2 자동 테스트, 실제 PostgreSQL/Neo4j CI, 화면 회귀, 배포 후 별도 가상 기록. 기존 기록 변경 없이 추가 마이그레이션으로 적용한다.

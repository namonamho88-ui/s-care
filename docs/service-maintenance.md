# 서비스 일시 중단 / 재개

현재 점검 모드는 기본 활성화되어 있다. Vercel에서 Railway 연결 없이 안내 HTML을 반환하며, `/api` 요청은 503 JSON으로 종료한다. 기존 기능과 데이터는 삭제하지 않는다. 화면에는 외부 폰트, 이미지, 스크립트, 자동 재시도 요청이 없다.

## 재개

1. Railway 백엔드를 재가동하고 정상 동작을 확인한다.
2. Vercel 프로젝트의 Production 환경변수 `SCARE_MAINTENANCE_MODE`를 `false`로 설정한다.
3. 재배포한 뒤 메인 화면, 로그인, 장애 조회를 확인한다.

다시 중단하려면 변수를 `true`로 변경하고 재배포한다. 변수가 없을 때도 중단 안내가 표시된다. 재구독 여부를 자동 감지하지 않는다.

안내 화면 배포는 Railway 구독이나 실행 중인 서비스를 중단하지 않는다. Railway 비용 관리는 별도로 수행해야 한다. 이미 열려 있는 화면은 새로고침해야 안내 화면으로 전환되지만, 이후 API 요청은 점검 응답으로 차단된다.

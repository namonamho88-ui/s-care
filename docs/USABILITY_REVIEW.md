# 화면 사용성 검토 — 2026-10-10

## 요청과 확인 결과

사용자·관리자 관점의 기능 안내와 온톨로지 전체화면을 보완했다. 기존 네모 아이콘은 React Flow의 Fit View(영역에 그래프 맞춤)였으며 전체화면 기능은 없었다. 기존 클라우드의 장애·승인·평가 데이터를 초기화하거나 사용자가 진행 중인 장애를 임의 승인하지 않았다.

| 확인한 문제 | 반영 내용 |
| --- | --- |
| 전체화면과 그래프 배율 맞춤의 구분 없음 | 전체화면 버튼, 웹 화면을 채우는 dialog, 닫기/Esc, 원래 버튼으로 포커스 복귀 |
| 그래프와 영향 분석을 어디서 보는지 불명확 | 독립 온톨로지 메뉴, 분석 기준 장애 선택, 상세에서 영향 그래프로 이동 |
| 영향 필터 전환 시 노드 측정 전 배율 계산 | 측정된 viewport 크기·노드 준비 상태에 따라 다시 맞춤, 그래프 구성 변경 시 내부 상태 분리 |
| 관계/자산 수가 고정 텍스트 | API 데이터에 따른 실제 수량 표시 |
| 화살표·색상·노드의 뜻 부족 | 전체/영향 필터, 범례, 클릭한 자산의 종류·연결 수, 한국어 확대/축소/전체 맞춤 접근성 이름 |
| 업무 역할별 설명과 다음 행동 없음 | 사용자/관리자 매뉴얼, 메뉴별 설명, 장애 상태별 다음 할 일 |
| 이력 필터가 관제 집계에도 적용되지만 안내 없음 | 필터 적용 안내·초기화, 제목/ID 검색, 하드코딩된 2026년 기본 기간 제거 |
| 입력한 후기를 저장하지 않고 종료 가능 | 변경 사항 저장 및 후기·예방 대책 입력 전 종료 비활성화 |
| 실패한 평가에 정상 점수 칸 표시 | 오류 메시지와 정상 점수 표시 분리 |
| 새 정적 매뉴얼 파일의 배포 누락 가능성 | standalone 시작 스크립트와 Docker 이미지에 public 복사 |

## 매뉴얼

- 화면의 **사용 안내**에서 사용자용/관리자용을 선택한다.
- 단일 원본: `frontend/content/manuals.json`.
- 생성: `cd frontend && npm run manuals`.
- 동일성 검사: `npm run manuals:check`.
- 저장소: `USER_MANUAL.md`, `ADMIN_MANUAL.md`.
- 웹/오프라인 인쇄용: `/manuals/user.html`, `/manuals/admin.html`. 브라우저 인쇄에서 PDF 저장 가능.
- 업무 역할을 구분한 안내이며 별도 사용자 권한, 개인별 계정 또는 SSO가 구현된 것으로 설명하지 않는다.

## 자동 검증

Next.js production build와 TypeScript 검사를 통과했다. `npm run test:ui`의 Chromium UI 회귀 테스트 **6개 통과**:

1. 전체화면 크기, 확대 후 모든 노드 맞춤, Esc와 포커스 복귀.
2. 분석 기준 장애 선택, 영향 자산 필터, 자산 정보 클릭, 선택 해제 시 이전 강조 제거.
3. 390×844 모바일 전체화면의 닫기·가로 넘침·그래프 높이.
4. 사용자/관리자 매뉴얼 전환, 인쇄 파일 HTTP 응답, 실패한 평가 오류 표시.
5. 장애 ID 검색, 공유 집계 필터 표시와 초기화.
6. 저장 전 종료 차단, 저장 후 종료 순서.

UI 테스트는 독립 가상 API fixture를 사용하며 실제 클라우드 DB·모델 테스트를 대신하지 않는다. GitHub frontend CI에도 매뉴얼 동일성 및 이 회귀 테스트를 추가했다. 실제 Jev/Hermes/DB 통합 검증 범위는 `VALIDATION.md`의 기존 클라우드 결과와 구분한다.

## 남은 범위

공통 관리자 토큰, 단일 backend replica, Skill 초안 수정·재생성 UI 미지원, 실제 TypeSafe API 미검증은 기존 제한이다. 지속 부하·실운영 보안 인증은 이번 화면 사용성 검토로 충족됐다고 주장하지 않는다. 관리자의 의미 검토가 여전히 필요하다.
